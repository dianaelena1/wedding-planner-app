# Sprint 3 — Taskuri și checklisturi

## Modificări
- modelul `WeddingTask` suportă checklisturi, furnizor, responsabil și termen relativ;
- checklisturile pot fi bifate direct din pagina Task-uri;
- statusul se actualizează automat: De făcut / În lucru / Finalizat;
- filtre noi pentru categorie și tipul taskului;
- import sigur, fără suprascriere, pentru checklisturile extrase din foile de organizare;
- checklisturi incluse: confirmări, logistică, hostese/coordonator, plan sală, candy bar, lumânări/decor, meniuri/numere de masă și plicuri/plăți.

## Utilizare
În pagina **Task-uri**, apasă butonul **Importă checklisturile din foi**. Importul adaugă doar elementele lipsă și poate fi apăsat din nou în siguranță.

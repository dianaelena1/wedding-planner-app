# Wedding Planner – prima etapă Firestore

Această versiune conține proiectul Angular complet și pagina **Furnizori** refăcută cu CRUD în Firestore.

## Pornire

```bash
npm install
npm start
```

## Prima utilizare

1. Autentifică-te în aplicație.
2. Intră la **Furnizori**.
3. Apasă o singură dată **Importă datele existente**.
4. După import poți adăuga, edita și șterge furnizori direct din interfață.

Colecția utilizată este `weddingVendors`.

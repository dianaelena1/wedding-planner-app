# Aspect vizual unitar

Am adăugat un design system global în:

```text
src/styles.scss
```

## Uniformizări incluse

- aceleași culori, dimensiuni și stări pentru butoane;
- aceleași carduri și umbre;
- mesaje unitare de succes, eroare, avertizare și informare;
- culori coerente pentru statusuri;
- câmpuri mai mari și mai clare;
- focus vizibil pentru tastatură;
- formulare pe o singură coloană pe telefon;
- butoane late pe ecrane mici;
- lista de plăți se transformă în carduri pe telefon;
- spațiere și titluri uniforme.

Nu sunt necesare modificări Firebase sau pachete noi.

După extragere:

```powershell
npm install
ng serve
```
